## 🪕 ฟีเจอร์ใหม่: โหมดอูคูเลเล่ (Ukulele Mode)
- สลับเครื่องดนตรีได้ระหว่าง **🎸 กีต้าร์โปร่ง (6 สาย EADGBE)** และ **🪕 อูคูเลเล่ (4 สาย GCEA)**
- ในโหมดอูคูเลเล่:
  - หน้าจอจะเปลี่ยนเป็นสายไนลอน 4 เส้น (G4, C4, E4, A4)
  - คอร์ดทั้ง 9 คอร์ดจะเปลี่ยนเป็นคอร์ดอูคูเลเล่มาตรฐาน:
    - **C:** `0 0 0 3`
    - **G:** `0 2 3 2`
    - **Am:** `2 0 0 0`
    - **F:** `2 0 1 0`
    - **Dm:** `2 2 1 0`
    - **Em:** `0 4 3 2`
    - **D:** `2 2 2 0`
    - **A:** `2 1 0 0`
    - **E:** `1 4 0 2`
  - ระบบเสียงจะเปลี่ยนเป็นเสียงบอดี้ไม้ขนาดเล็ก (~420Hz Resonance) และสายเอ็นเสียงกังวานใสสดใสสไตล์ฮาวาย

## 🔊 ฟีเจอร์ใหม่: ปุ่มเพิ่มเสียง - ลดเสียง (Volume Controls)
- มีปุ่ม **`🔉 - (ลดเสียง)`** และ **`🔊 + (เพิ่มเสียง)`** ปรับทีละ 10%
- มีแถบเลื่อน Volume Slider ปรับระดับความดังได้ 0% ถึง 100%
- มีตัวเลขแสดงผลเปอร์เซ็นต์ความดังชัดเจน
- ปรับได้ทั้งบนมือถือและคอมพิวเตอร์ (หรือกดปุ่ม <kbd>+</kbd> และ <kbd>-</kbd> บนคีย์บอร์ด)

---

## 📱 แผงปุ่มสำหรับเล่นบนโทรศัพท์มือถือ (Mobile Controller)
- **⬇ ดีดลง (DOWN):** ดีดคอร์ดเต็มเสียง
- **⬆ ดีดขึ้น (UP):** ดีดสะบัดสายแหลม
- **🎶 เกา 1 ห้อง (ARP):** เกาโน้ตตามคอร์ดวน 1 ห้องเพลงทันที
- **✋ อุดสาย (MUTE):** หยุดเสียงทันที พร้อมเสียงตบสาย Palm Slap
- **▶/⏹ เล่นออโต้:** สลับเปิด/ปิดจังหวะตีคอร์ดอัตโนมัติ (Pop, Rock, Ballad)
